# Границы переноса Dotify

Состояние на 19 октября 2026, сверено с adaptation.json и entry.jsx

Исходный EXE не пересобран. Из него извлечены 162 статических ресурса, которые сохраняются с проверкой SHA-256
Для выполнения внутри Spotify выбранные React-компоненты из этих ресурсов собираются с адаптером сервисов
Полного переноса всех функций Dotify нет

| Часть | Текущее состояние |
| --- | --- |
| Оболочка, навигация | Исходные Wf и Xj, CSS и переходы Dotify |
| Главная | Исходная композиция, данные библиотеки и истории Spotify, без сервиса персональных подборок Dotify |
| Поиск | Исходные компоненты, штатный GraphQL поиска Spotify; публичный Web API только при отсутствии GraphQL |
| Плеер, миниплеер, полноэкранный вид | Исходные компоненты, управление движком Spotify |
| Очередь, текст | Исходная правая панель и переключатель, адаптер очереди Spotify и доступного текста |
| Библиотека | Исходный экран и карточки, адаптер плейлистов, избранного, альбомов, подписок |
| Темы, шрифты, вкладки | Исходные компоненты и палитры, локальное сохранение |
| Кастом, пресеты | Исходное меню, фон и эффекты, браузерный импорт/экспорт и IndexedDB |
| Контекстное меню трека | Частично адаптировано; SoundCloud удалён, закрепление, скачивание и волна по треку не реализованы |
| Профиль | Кнопка ведёт на обычную страницу профиля Spotify, исходный профиль Dotify не перенесён |
| Страницы артистов, альбомов | Переходят на штатные страницы Spotify; единое оформление Dotify на них отсутствует |
| Аудио | Исходное меню `_i`, качество, нормализация, gapless, crossfade и устройства через SettingsAPI/ExclusiveModeAPI Spotify; неподдерживаемое приглушение Windows исключено |
| Оверлей | Исходные настройки `Ai` и renderer `view-Bg7pA49X`, отдельный прозрачный WebView2, четыре режима, размеры, положение, форма, прозрачность, Alt+K |
| Кнопки окна | Исходный компонент `af`; команды сворачивания, размеров, полного экрана и закрытия через локальную реализацию Windows |
| Системные настройки, глобальные клавиши | Tauri/Rust не перенесён; для оверлея реализован Alt+K, произвольное переназначение глобальных сочетаний не перенесено |
| Аудиодвижок, DSP, визуализатор, Canvas | Собственный аудиодвижок Dotify не используется, неподдерживаемые функции скрыты |
| Мастерская, друзья, совместные комнаты, сервисы Dotify | Не подключены, зависят от исходной инфраструктуры Dotify |

Оболочка выполняется в srcDoc iframe для изоляции React Dotify от версии React Spotify
На её странице штатные панели Spotify скрыты, при уходе на обычные маршруты восстанавливаются
Следовательно, это Custom App и частичная замена интерфейса, а не полная замена клиента
Перенос оставшихся экранов требует адаптации их данных и действий; отдельная реализация Windows для оверлея и кнопок окна не переносит остальные возможности Tauri

Локальные тесты, деморежим и успешный Spicetify apply не подтверждают работу всех действий с живыми аккаунтами

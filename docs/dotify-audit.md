# Dotify: исследование установленного приложения

Дата: 18 октября 2026

## Новая граница дизайна

Пользователь запросил весь визуальный язык установленного Dotify, а не только отдельную страницу «Моей волны»
Маркетплейс и панель друзей исключены
Кнопки и действия должны соответствовать Spotify
Следующая редакция дизайна должна опираться на установленное приложение, а затем показываться для правок в чате
Предыдущие варианты «Студия», «Погружение», «Минимал» не являются подтверждёнными копиями установленного Dotify
Выбор «Студия» в макете не отменяет этот новый запрос

## Что подтверждено

Установленное приложение: `C:\Program Files\Dotify\dotify.exe`
Версия файла и продукта: `2.3.7+rev.3`
Окно Dotify найдено через Computer Use
Один раз успешно прочитано дерево UI Automation главного экрана

В дереве главного экрана обнаружены:

- Навигация: Главная, Плеер, Поиск, Библиотека, Настройки
- Моя волна с кнопкой выбора режима «Обычная»
- Персональная подборка и блок приветствия
- Секции релизов и плейлистов
- Карточки музыки с действиями Слушать, Добавить в библиотеку, В очередь
- Нижний плеер с обложкой, названием и исполнителем
- Нравится, Скорость воспроизведения, Volume, Очередь
- Кнопка Открыть текст на весь экран
- История и Новости · Уведомления
- Часть транспортных кнопок не имеет доступного текстового имени

Это подтверждает наличие элементов и структуру доступности
Это не подтверждает их цвета, размеры, расположение, анимацию или работу вложенных меню

## Блокер осмотра

Снимки установленного Dotify не получены
Computer Use вернул `FrameArrived timed out: timed out waiting on channel`, затем `window capture timed out: timed out waiting on channel`
После обновления выбора окна и повторного открытия приложения захват не восстановился
Далее UI Automation также перестал возвращать дерево интерфейса
Повторное использование старых индексов и координат прекращено

Повторная попытка по просьбе пользователя:

- UI Automation снова вернул структуру главной страницы
- Нажатие на свежий элемент вкладки Плеер заблокировано ошибкой `coordinate input geometry is unavailable`
- Проверены активация окна, действие Raise и навигация Tab
- Окно штатно закрыто через Alt+F4 и повторно открыто через установленный идентификатор приложения
- После повторного открытия захват снова вернул `window capture timed out: timed out waiting on channel`
- Полный перезапуск процесса не подтверждён: после открытия вернулся тот же идентификатор окна

Не подтверждены:

- Реальный экран Плеер и полноэкранный режим
- Воспроизведение музыки и изменения визуала во время проигрывания
- Очередь в открытом виде
- Контекстное меню трека
- Поиск и фильтры результатов
- Разделы библиотеки, страницы альбома, исполнителя и плейлиста
- Настройки внешнего вида, плеера и остальных категорий
- Тексты песен, дополнительные режимы и анимации

## Привязка к проекту

| Область | Как должна адаптироваться |
| --- | --- |
| Визуальный язык Spotify целиком | Потребуется тема Spicetify для стандартных страниц и панелей |
| Главная и Моя волна | Custom App с рекомендациями Яндекса и воспроизведением через Spotify |
| Транспорт плеера | Существующий адаптер Spicetify.Player и контроллер волны |
| Нравится | Избранное Spotify и Яндекса, с подтверждением изменения |
| Очередь | Очередь Spotify в обычном режиме, управление волной в режиме Яндекса |
| Поиск и библиотека | Действия над каталогом и библиотекой Spotify |
| Тексты и дополнительные функции | Подключать только при наличии реально проверенного источника и доступного API |
| Скорость воспроизведения | Не переносить как работающую музыкальную функцию без проверки поддержки Spotify |
| Маркетплейс и друзья Dotify | Не включать |

Текущий проект реализует Custom App и мост
Общая тема Spotify пока не создана
В рамках первоначального осмотра исходный плеер не переделывался по неподтверждённым визуальным предположениям

## Состояние переноса после референсов

В исходном Custom App заменена прежняя тёплая концепция на чёрную компоновку по скриншотам
Добавлены навигация, обычный/круглый/большой плеер, открытие полноэкранного вида с обложки, очередь и текст в боковой панели, библиотека и поиск Spotify
Визуальные настройки сохраняются в localStorage с проверкой значений
API-запросы библиотеки, текста и поиска подготовлены по документации и исходникам Spicetify; реальная работа в клиенте ещё не проверена

Не завершены:

- Глобальная тема стандартных страниц Spotify и общая навигация вне Custom App
- Нативное окно оверлея Windows и глобальные сочетания клавиш
- Точное воспроизведение всех переходов и состояний из видео
- Волна по произвольному треку, сопоставление Spotify → Яндекс, пункты Следующим/Скачать/Закрепить
- Визуализатор от реального аудиосигнала, Canvas и waveform из реальных данных
- Все дополнительные темы и пользовательские фоны

Разделы с функциями исключительно Dotify, маркетплейс и друзья исключаются по прямому указанию пользователя

## Адаптация оригинальных компонентов, 19 октября

Предыдущая приблизительная реализация заменена выбранными компонентами извлечённого фронтенда
Сборка включает три исходных CSS, исходные шрифты, React/Radix/Motion и компоненты страниц, настроек, миниплеера, полноэкранного режима и правой панели
Палитры, пользовательские темы, шрифты, скругления и пресеты миниплеера подключены к сохраняемым настройкам
Восстановлены исходный компонент изображений, оформление заголовков и раскрытие громкости
Переключение правой панели теперь сохраняет её DOM, поэтому штатный переход transform/visibility отрабатывает при открытии и закрытии

Это перенос интерфейса внутри Custom App, а не полная замена оболочки Spotify
Оверлей Windows, глобальные клавиши, анализатор аудио, Canvas и Dotify-only сервисы остаются за границей реализованной интеграции
Работу со Spotify и Яндексом ещё необходимо проверить в подключённом клиенте
